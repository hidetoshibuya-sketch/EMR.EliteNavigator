プロジェクト概要

日本の救急隊員（消防士・救急救命士）が英語話者の傷病者を診る際に使う、バイリンガル(英/日)の HTML/PWA 単一ファイルアプリ。

デプロイ先hidetoshibuya-sketch.github.io/EMR.EliteNavigator/

ローカル~/Documents/EMR.EliteNavigator/
バージョンv2.8.7
対応端末iPhone Safari + Android Chrome（PWA ホーム画面追加可）

技術スタック

  • 単一 HTML + 埋め込み JS/CSS（ビルドステップなし、index.html ~4751 行）
  • Web Speech API（SpeechSynthesis + SpeechRecognition）
  • 事前録音音声: macOS say -v Samantha -r 175、.m4a(AAC)、audio/ に約546ファイル
  • PWA: Service Worker（assets は cache-first、HTML は network-first）+ manifest
  • jsPDF + html2canvas で 1ページ Letter PDF（内容量に応じ自動縮小）
  • Web Share API で iOS 共有シート連携（メール送信に使用）
  • デザイン: フラット・不透明（旧 Liquid Glass は v2.8.5 で全廃。背景 #eef2f7、白カード+細枠線、ぼかしなし）

デプロイ手順 (Mac)

cd ~/Documents/EMR.EliteNavigator
git add -A
git commit -m "vX.X: 変更内容を記述"
git push origin main
重要: コード変更時は sw.js の CACHE_VERSION を必ず変更（例 ...-9 → ...-10）。忘れると古いキャッシュが残る。

iPhone更新確認: アイコン長押し→Appを削除 → Safariでサイトを開く → 反映確認 → 共有→ホーム画面に追加。

既知の挙動・制約

  • 音声は .mp3 → .m4a → .wav → .ogg 順フォールバック。ファイル不在時は live TTS。質問ボタン(ask-*)は事前録音なしで TTS 読み上げ（仕様）
  • iOS Speech API 対策: 90文字チャンク、anti-GC array、pause/resume keep-alive
  • PWAキャッシュ更新は sw.js の CACHE_VERSION 依存
  • CPRチャートは表示専用・音声なし。triage音声はファイル残るが未使用
  • メール送信は Web Share API 依存。非対応環境（PC等）は PDF ダウンロードにフォールバック
  • SSN はマスクせず画面・PDFともそのまま表示
